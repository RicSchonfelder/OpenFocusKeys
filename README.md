# OpenFocusKeys

Exibe atalhos de teclado do programa em foco na segunda tela.

## Como usar

1. Execute `start.bat` (ou `python app.py`)
2. Os atalhos aparecem na segunda tela conforme você troca de programa
3. A janela fica no fundo — outras janelas podem ser arrastadas sobre ela
4. Para fechar: `Ctrl+Q` em qualquer programa, ou mate o processo `python.exe`

## Atalhos mapeados

Edite `shortcuts.json` para adicionar ou alterar atalhos. A chave é o nome do `.exe` do programa.

Programas incluídos: Chrome, Edge, Firefox, VS Code, Visual Studio, Explorer, Notepad, Notepad++, Windows Terminal, PowerShell, Slack, Discord, Spotify, Excel, Word, PowerPoint.
